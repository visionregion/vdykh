# Як долучитися до проєкту

Дякуємо за інтерес до проєкту **Вдих**! Будь-яка допомога цінна: від коментаря лікаря до схеми друкованої плати.

## Способи допомогти

- **Обговорення та ідеї** — відкрийте [Issue](../../issues) з описом пропозиції чи питання.
- **Клінічна експертиза** — якщо ви лікар, ваші коментарі щодо точок аускультації, вимог до якості звуку та сценаріїв використання особливо важливі.
- **Технічний внесок** — схеми, код, документація через Pull Request.
- **Тестування** — коли з'явиться прототип, шукатимемо людей для перевірки якості записів (лише на добровольцях і без реальних діагностичних цілей).

## Як подати зміни

1. Зробіть fork репозиторію.
2. Створіть окрему гілку для змін: `git checkout -b назва-змін`.
3. Опишіть зміни зрозуміло — що і навіщо змінено.
4. Відкрийте Pull Request і в описі підтвердіть згоду з угодою учасника (див. нижче).

## Важливо

- **Не публікуйте записи реальних пацієнтів** без їхньої письмової інформованої згоди та знеособлення. Див. [DISCLAIMER.md](DISCLAIMER.md).
- Додавайте лише власні матеріали або матеріали, які ви маєте право передати. Якщо використовуєте сторонні компоненти, бібліотеки чи схеми — вкажіть джерело та ліцензію.
- Будьте ввічливими й поважайте інших учасників.
