# Компоненти для етапу 1 — перевірка концепції

*Мета етапу: за 2–4 тижні й невеликі гроші зрозуміти, чи можна в домашніх умовах отримати запис дихальних шумів достатньої для лікаря якості.*

Ціни орієнтовні, у доларах США; у різних магазинах можуть суттєво відрізнятися.

## Інструменти

- Паяльник, припій, флюс
- Мультиметр
- Доступ до 3D-принтера (необов'язково на старті)
- Навушники з хорошою передачею низьких частот — для прослуховування записів

## Програмне забезпечення

- Arduino IDE або PlatformIO / ESP-IDF для прошивки ESP32-S3
- Audacity або Sonic Visualiser — прослуховування та спектрограми
- Python (numpy, scipy, librosa) — аналіз записів, порівняння варіантів

## Експерименти етапу 1

1. **Варіанти акустичного з'єднання:** мікрофон безпосередньо в голівці vs через короткий відрізок трубки; різний об'єм камери.
2. **Порівняння мікрофонів** — який дає найкраще відношення сигнал/шум у діапазоні 100–2000 Гц.
3. **Віднімання шуму** другим мікрофоном: увімкнений телевізор, розмова, вентилятор.
4. **Вплив натиску** — як якість залежить від сили притискання (дані з FSR).
5. **Сліпе порівняння з лікарем:** лікар слухає звичайним стетоскопом і записи прототипу з тих самих точок — чи чути ту саму картину.

**Результат етапу:** записи з кількох точок у добровольців + висновок лікаря щодо якості + рішення щодо архітектури етапу 2.
