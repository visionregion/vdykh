# Технічна концепція пристрою

*Версія 0.1 — концепція, жоден з параметрів ще не перевірено на практиці.*

## 1. Принцип

Пристрій зберігає класичну акустичну голівку стетоскопа, бо діафрагма збирає звук з поверхні тіла значно краще за «голий» мікрофон. Замість трубок і навушників за діафрагмою розташована герметична повітряна камера з цифровим мікрофоном.

## 2. Акустична частина

| Компонент | Вимоги | Примітки |
|---|---|---|
| Голівка з діафрагмою | ⌀ ~45 мм | Розмір дорослої голівки; для дітей — менша |
| Акустична камера | Герметична, малий об'єм | Форма і об'єм — предмет експериментів на етапі 1 |
| Основний мікрофон | MEMS, цифровий I2S/PDM, SNR ≥ 65 дБ | Напр. ICS-43434, IM69D130, SPH0645 |
| Мікрофон шуму | MEMS, спрямований назовні | Для віднімання фонового шуму кімнати |

**Частотний діапазон:**
- дихальні шуми — приблизно 100–2000 Гц (свисти — нижча частина, крепітація — вища);
- тони серця — приблизно 20–200 Гц.

**Параметри запису:** 8–16 кГц, 16–24 біти, моно на кожен мікрофон.

## 3. Датчики якості запису

- **Датчик тиску / контакту** (FSR або тензодатчик) — визначає, чи щільно притиснута голівка. Нещільний контакт — найчастіша причина поганих домашніх записів.
- **Акселерометр (IMU)** — виявляє рухи, що створюють артефакти; потенційно допомагає визначати фазу дихання за рухом грудної клітки.

## 4. Електроніка

| Компонент | Варіант для етапу 1 | Варіант для етапу 2 |
|---|---|---|
| MCU + Bluetooth | ESP32-S3 | Nordic nRF5340 (BLE Audio, LC3) |
| Пам'ять | Вбудована flash / microSD | SPI flash 16–64 МБ |
| Живлення | LiPo 300–500 мА·год | Те саме + контроль заряду |
| Заряджання | Модуль TP4056 / USB-C | USB-C на платі |
| Керування | 1 кнопка, RGB-світлодіод | Те саме, можливо вібромотор |

### Режим передачі даних

**Спочатку запис у пам'ять, потім передача файлу.** Потокова передача аудіо по Bluetooth вносить втрати й артефакти; для лікаря важливіша якість, ніж передача в реальному часі. Запис однієї точки — 15–20 секунд (≈0,5 МБ на 16 кГц / 16 біт).

## 5. Корпус

- Матеріал, стійкий до дезінфекції спиртовими розчинами.
- Без щілин і швів, де накопичується бруд.
- Зручний хват для самостійного прикладання до передньої та бічної поверхні грудної клітки.
- Можлива насадка-ручка для самостійного запису зі спини.

## 6. Застосунок (концепція)

1. **Покрокові точки аускультації** на силуеті тулуба: 6–8 спереду та збоку, 4–6 на спині. Можливі AR-підказки через камеру.
2. **Інструкція з дихання** — візуальний ритм «вдих-видих» відкритим ротом.
3. **Автоматична перевірка якості** після кожної точки: контакт, рівень шуму, тертя одягу, домінування тонів серця. При поганій якості — повторний запис.
4. **Передача записів** у захищене хмарне сховище.
5. **Інтерфейс лікаря:** прослуховування кожної точки, спектрограма, позначки підозрілих ділянок, порівняння з попередніми записами.

## 7. Обробка звуку та ШІ

- Фільтрація, віднімання шуму за допомогою другого мікрофона, нормалізація.
- Класифікація патологічних звуків (свисти, хрипи, крепітація).
- Відкриті набори даних для досліджень: ICBHI 2017 Respiratory Sound Database, HF_Lung, SPRSound.
- **Для сертифікації знадобляться власні клінічні записи, верифіковані лікарями.**

## 8. Відомі проблеми та відкриті питання

- **Точки на спині** — найінформативніші для легень, але самостійно туди не дістатися. Варіанти: допомога члена родини, насадка-ручка, запис медсестрою в амбулаторії.
- **Тертя одягу та волосся на грудях** — потребує алгоритмів виявлення артефактів.
- **Тони серця** заважають аналізу дихальних шумів у деяких точках.
- **Регуляторика** — серійний пристрій для діагностики буде медичним виробом і потребуватиме сертифікації.
