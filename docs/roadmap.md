# План розвитку

*Терміни й бюджети орієнтовні та залежать від команди і фінансування.*

## Етап 0 — Концепція ✅

- Технічна концепція пристрою
- Публікація проєкту, пошук однодумців
- Перші розмови з лікарями щодо клінічних вимог

## Етап 1 — Перевірка концепції ⏳

**Термін:** 2–4 тижні · **Бюджет:** $50–150

- Збирання прототипу на готових модулях (ESP32-S3, MEMS-мікрофони, голівка звичайного стетоскопа)
- Експерименти з акустичною камерою та мікрофонами
- Перші записи на добровольцях
- Сліпе порівняння з класичною аускультацією за участі лікаря

**Критерій успіху:** лікар у більшості точок чує на записі ту саму картину, що й звичайним стетоскопом.

Компоненти: [bom-stage1.md](bom-stage1.md)

## Етап 2 — Функціональний прототип ⬜

**Термін:** 2–4 місяці · **Бюджет:** $2–5 тис.

- Власна друкована плата на nRF5340
- Корпус, надрукований на 3D-принтері, з урахуванням ергономіки
- Базовий мобільний застосунок: точки аускультації, інструкція з дихання, перевірка якості
- Перші алгоритми шумозаглушення

## Етап 3 — Клінічна перевірка ⬜

**Термін:** 3–6 місяців

- Пілот із кількома сімейними лікарями
- Порівняння записів із класичною аускультацією на більшій вибірці
- Збір розмічених лікарями даних для навчання ШІ (з інформованою згодою пацієнтів)
- Вибір сценарію для точок на спині: допомога родини, насадка або медсестра

## Етап 4 — Передсерійний зразок ⬜

- Промисловий дизайн корпусу
- Система управління якістю (ISO 13485), документація за IEC 62304 для ПЗ
- Підготовка до оцінки відповідності як медичного виробу
- Пошук виробничого партнера

## Паралельні напрями

- **Застосунок для лікаря** — прослуховування записів, спектрограми, історія пацієнта
- **ШІ-аналіз** — розпізнавання свистів, хрипів, крепітації
- **Інтеграція** з ширшою платформою ШІ-асистента для сімейного лікаря
